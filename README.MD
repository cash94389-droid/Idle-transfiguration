# Idle Transfiguration
### Blade & Sorcery: Nomad

A Mahito-inspired soul manipulation mod.

## Features
- NPC soul grabbing
- Toggle-based time freeze
- Blue spectral soul visualization
- Two-handed soul manipulation
- Body stretching and deformation
- Body part merging
- Apply transformations when time resumes

## Target Platform
Meta Quest 2, 3, and 3S

## Development Status
Prototype development.
